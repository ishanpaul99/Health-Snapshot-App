# Health Snapshot

Health Snapshot is a health and wellness web application designed to help users better understand their physical health through quick and accessible calculations. The application allows users to calculate their Body Mass Index (BMI), determine their BMI category, discover their ideal weight range, and estimate daily calorie requirements based on personal information and activity level.

The application also provides personalized health recommendations and color-coded status indicators based on BMI results. User information is automatically saved locally, allowing convenient access to previous entries even after refreshing or reopening the application.

## Features

- BMI calculation and category analysis
- Ideal weight range estimation
- Daily calorie requirement calculation
- Personalized health recommendations
- Color-coded health status indicators
- Local storage support for saved data
- Responsive design for desktop and mobile devices
- Simple and modern user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Development

The initial codebase was generated with the assistance of Cursor AI as part of an AI-assisted development workflow.

Further customizations were implemented manually, including health calculation refinements, user interface improvements, logo integration, validation enhancements, testing, and overall application polishing.
